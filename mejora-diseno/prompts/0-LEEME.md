# Cómo usar estos prompts
Pasalos a Cursor **de a uno**, en orden, desde la raíz del repo (`cercadelestadio/`). Después de cada uno corré `cd web && npm run lint && npm run build`, mirá el sitio con `npm run dev` en 1440 y 390 px y commiteá antes de pasar al siguiente.
Referencias: copiá `audit/propuesta/` (tokens.css, base.css, home.html, capturas) a `cercadelestadio/docs/design/` para que Cursor las pueda leer.
